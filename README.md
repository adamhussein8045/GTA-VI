# GTA VI  

A bilingual (English / Arabic), responsive fan-made GTA VI information website built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the `GTA-VI` folder.
2. Open `index.html` in a modern browser.
3. For the best local development experience, open the folder in VS Code and use a local static server (for example, the Live Server extension).

## Project structure
- `index.html` — page structure and content
- `css/style.css` — visual design, responsive layout and RTL support
- `js/script.js` — language switching, mobile navigation, gallery lightbox and streamer idea generator

## Notes
- This is an independent fan-made project, not affiliated with Rockstar Games.
- Gallery and hero photos are illustrative remote stock images, not official GTA VI screenshots.
- Images and Google Fonts require an internet connection. Replace remote image URLs with licensed local assets if you plan to publish the site.
- Official game/platform information should be checked on Rockstar's website before publishing updates.
- The official launch platform information currently lists PlayStation 5 and Xbox Series X|S. The game contains mature content; review the local age rating with a parent or guardian.
